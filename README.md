# AICE Associate 독학 키트 (비공식)

AICE Associate 시험을 혼자 준비하기 위한 브라우저용 학습 도구입니다. 설치 없이 `aice selfstudy.html`을 브라우저로 열면 됩니다. 처음 열 때 Python 엔진([Pyodide](https://pyodide.org))을 내려받는 데 20초쯤 걸립니다.

- **학습 계획**: 4주 체크리스트
- **핵심 개념**: 단원별 핵심 코드와 자주 빠지는 함정
- **API 퀴즈**: 오류 정정 문항에 자주 나오는 API 18문제
- **모의고사**: 통신사 고객 이탈 예측(분류) 14문항, 100점. 브라우저에서 코드를 실행하고 자동 채점합니다.
  - 13번 딥러닝 문항은 브라우저에서 TensorFlow를 실행할 수 없어 코드 구조만 채점합니다.

## 저작권 안내
문항과 데이터는 모두 새로 만든 것입니다. 공식 샘플문항의 지문·코드·데이터는 포함하지 않습니다. 이 도구는 AICE 공식 서비스가 아니며, 실제 시험 문항·채점 기준과 다를 수 있습니다. 시험 정보는 [aice.study](https://aice.study)에서 확인하세요.

## 개발
- `aice_core.py`: 합성 데이터 생성, 셀 실행, 채점 로직 (Pyodide에서 실행)
- `build.py`: `aice_core.py`를 HTML 안에 붙여 넣습니다. 코어를 고친 뒤 `python build.py`를 실행하세요.
- 자가 진단: HTML 주소 끝에 `#selftest`를 붙여 열면 모범답안 14개가 모두 정답 처리되는지 확인합니다.
